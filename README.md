# Quiz Builder

A lightweight single-page quiz builder app.

## Features
- Add/edit quiz questions manually
- Import .txt formatted questions
- Start quiz with current questions
- Review results and show wrong-only filter

## Files
- `index.html`: Main web page
- `styles.css`: UI styles
- `script.js`: App logic

## Run locally
1. Open `index.html` directly in browser, or
2. From project folder run:
   ```bash
   python -m http.server 8000
   ```
   then visit `http://localhost:8000`
