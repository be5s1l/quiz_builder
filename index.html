📋File Format Guide

Save your questions as a plain .txt file using this structure:

1) Your question text here ? * Correct answer option Wrong option B Wrong option C Wrong option D 2) Another question ? * Correct answer Wrong option B Wrong option C Wrong option D

Rules:
• Start each question with a number + ) or . — e.g. 1), Q1.
• Place * on its own line right before the correct answer
• Each question needs exactly 4 options
• Blank lines between questions are fine
• Noise lines like Bloom Level:, 1/1, Correct ✅ and Arabic comments are auto-skipped
